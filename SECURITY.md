# Security / Privacy

- Không commit dữ liệu học sinh thật lên repository công khai.
- Không commit `.env`, API keys, service-account JSON, JWT secrets hoặc mật khẩu production.
- Bản demo hiện dùng dữ liệu giả lập trong `data.js`.
- Khi nối Google Sheets/Database thật, thông tin xác thực phải đặt trong environment variables phía server.
